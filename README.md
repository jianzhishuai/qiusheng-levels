# 秋生trader 关键点位 · 图文溯源站

@Hoyooyoo（秋生trader）公开推文中的**最新关键点位**汇总，含推文原文与配图交叉验证。

## 在线查看
`https://jianzhishuai.github.io/qiusheng-levels/`

## 文件说明
| 文件 | 说明 |
|---|---|
| `index.html` | 主页面：单文件、数据内联、页内可直接编辑表格 |
| `images/` | 14 张推文原图（已本地化，不依赖 Twitter CDN） |
| `秋生trader_关键点位与图文溯源.xlsx` | Excel 版：4 个工作表，图已嵌入单元格 |
| `秋生trader_关键点位.csv` | CSV（UTF-8 BOM），可直接导入飞书/腾讯文档/Excel |
| `秋生trader_关键点位.tsv` | TSV，复制后直接粘贴进飞书表格 |

## 怎么编辑
页面右上角 **「✎ 开启编辑」** 可直接改表格，修改保存在本机浏览器（localStorage）。
改完点 **CSV / TSV / Markdown** 按钮导出，再覆盖回本仓库的 `index.html` 即可长期生效。

## 数据来源
推文正文经 nitter 镜像抓取，图片直链来自 pbs.twimg.com，逐条与图上标注交叉验证。
